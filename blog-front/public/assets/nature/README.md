# Kenney Nature Kit

Source: https://kenney.nl/assets/nature-kit
License: CC0 (see LICENSE.txt, included from the original download).
Files: grass_large.glb, tree_palmBend.glb, rock_largeA.glb, rock_tallA.glb, plant_bush.glb.
The original model geometry and colors are reused. The scene instances these files locally and adds wind through a vertex shader; no runtime third-party requests are needed.
