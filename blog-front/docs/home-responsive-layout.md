# 个人数字花园的响应式布局

首页以流式容器布局，内容宽度上限 1600px，左右留白通过 clamp 随窗口调整。短窗口保持自然纵向滚动，不强行把首屏压入视口。

## 布局规则

| 窗口宽度 | 首屏 | 小组件 | 导航与文章区 |
| --- | --- | --- | --- |
| 小于 480px | 单列，插画按比例缩放 | 单列 | 折叠菜单，文章自动单列 |
| 480–759px | 单列 | 两列，灵感卡独占下一行 | 折叠菜单 |
| 760–1099px | 双列 | 两列，灵感卡独占下一行 | 折叠菜单，侧栏移至文章下方 |
| 1100px 及以上 | 双列 | 三列 | 完整导航，文章与侧栏并排 |

插画使用 aspect-ratio 和百分比定位，星球、五官、轨道与卫星共同缩放。文章卡片用 auto-fit 自动决定列数。底部工具栏根据实际内容宽度布局，受视口宽度与底部安全区域限制。触摸设备不会应用卡片悬停倾斜。

在 Chromium 中使用临时 API 测试数据验证完整的文章轮播、列表和侧栏。测试数据仅注入独立测试浏览器，未加入应用。
