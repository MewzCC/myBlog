# 私人信号站的响应式布局

首页使用流式容器，内容宽度上限 1520px，左右留白通过 clamp 调整。短窗口自然纵向滚动，不强行压缩内容。

| 窗口宽度      | 首屏                   | 控制舱                 | 导航与文章区               |
| ------------- | ---------------------- | ---------------------- | -------------------------- |
| 小于 480px    | 单列，线框插画等比缩放 | 单列                   | 折叠菜单，文章单列         |
| 480–759px     | 单列                   | 两列，指令舱独占下一行 | 折叠菜单                   |
| 760–1099px    | 双列                   | 两列，指令舱独占下一行 | 折叠菜单，侧栏位于文章下方 |
| 1100px 及以上 | 双列                   | 三列                   | 完整导航，文章与侧栏并排   |

线框灵感体以 SVG 数学投影绘制，轨道使用百分比定位，视觉容器裁剪旋转轨道的外溢区域。文章列表使用 auto-fit 决定列数。浮动工具栏适应内容宽度并考虑底部安全区域。触摸设备不启用鼠标倾斜；减少动态效果偏好会关闭动画，Canvas 在页面隐藏时暂停，并限制像素密度。

## 验证记录

2026-10-12 在 Chromium 中分别验证昼间和夜间模式，使用临时 API 测试数据覆盖完整文章轮播、列表与侧栏。测试数据仅注入独立测试浏览器，未加入应用。

每种模式检查 22 组视口：280×653、320×568、360×800、390×844、479×900、480×800、640×360、759×900、760×900、768×1024、820×1180、900×600、1024×768、1099×720、1100×720、1280×720、1366×768、1440×900、1920×1080、2560×1080、3440×1440、3840×2160。

两种模式均无页面横向溢出、关键控件超出视口或导航区域互相重叠。交互测试覆盖主题持久化、频道切换、视觉调频、发射信号与快捷指令。浏览器视口模拟不代表真实手机或 Safari 设备测试。
