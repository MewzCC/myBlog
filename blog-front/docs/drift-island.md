# Drift Island · 可驾驶的 3D 个人主页

分支：`zcc/3d-drift-island`。信号站旧版保留在 `zcc/personal-signal-station`（318470e），数字花园保留在 `zcc/personal-digital-garden`。

## 运行

在 `blog-front` 目录执行 `npm ci`、`npm run dev`，访问 Vite 输出的地址（默认 http://127.0.0.1:3000/）。`npm run build` 生成可部署资源。首页按需加载 Three.js 与 Rapier，非首页不加载物理引擎；首页也不请求旧版 30 MB 视频背景。

后端接口仍使用现有 `/api/blogger/profile`、`/api/articles` 和站点设置。后端无法连接时，岛屿仍可驾驶，介绍使用默认文本，文章站点显示连接提示；没有向生产页面注入测试文章。

## 建模与玩法

所有 3D 模型和材质均由本项目程序生成，无模型 CDN 或额外材质包：

- 小车：圆角车身、玻璃、车门和后视镜、轮胎胎纹与轮毂、行李架、带皮带的行李箱、天线、头灯与尾灯。
- 岛屿：104×96 的沙滩地基，面积约为初版 64×60 的 2.6 倍。双公路环线与四条连接路、路沿、道路标线、斑马线、围栏、外移后的码头与帆船；物理海岸、全岛镜头和 SVG 地图同步扩展。
- 四个站点：条纹灯塔（阳台、栏杆、灯室与旋转光束）、创作车库（屋顶太阳能板、天线）、书店（条纹雨棚、书堆、烟囱）、邮局（邮筒、信槽）。停靠后打开真实文章、关于页或留言页。
- 景物：松树、棕榈树与椰子、花盆、长椅、岩石、风机、暖色路灯、漂浮云、海鸟、波动海面与海岸泡沫边缘。
- 玩法：8 枚金色灵感碎片、可碰撞移动的木箱、南侧跳台、站点发现计数、车辆实时小地图。
- 四个新区域：西侧森林池塘（荷叶、花朵、卵石与夜间萤火虫）、三处露营地（帐篷、睡袋、灯笼和跳动篝火）、东侧港口集市（柠檬水摊、水果篮、街机店）、北侧木板观景台（望远镜、花带与海滩遮阳伞）。
- 七位岛民：MOMO 邮差机器人、橘子赤狐、泡泡小鸭、慢慢水豚、棉花露营兔、BOLT 港口机器人、米酥观景猫。原创程序模型包含各自的耳朵、嘴、尾巴、背包和运动腿部。

岛民使用与头部、躯干、手臂及腿部模型外轮廓一致的复合碰撞体，以动态刚体速度控制巡游，不直接改写位置。车辆的真实接触开始事件触发伤害：车速至少 1.2 米/秒，每次 8–40 HP，间隔至少 0.7 秒。碰撞后切换为 4–6 个通过颈部、肩部与髋部关节连接的动态刚体，传递车辆方向上的速度和翻滚力，受重力、地面、车辆及场景障碍影响。倒地的每个身体部件始终保留碰撞，球形与限位铰链关节防止身体散开。轻伤约 2.8 秒后尝试起身，HP 归零则至少休息 12 秒，再恢复至 100 HP 并获得 1 秒保护。恢复前射线确定地面高度，并检查站立体积；被车辆或障碍占据时选择旁边的安全位置，约 0.65 秒过渡到站立。暂停或打开面板时模拟计时暂停。静止贴近不持续扣血；图鉴“寻找”按钮将实际车辆移到岛民附近。

Three.js 使用标准 PBR 材质、ACES 色调映射和实时阴影。Rapier 提供重力、刚体碰撞、CCD 防穿透及道具模拟；驾驶使用固定 60 Hz 物理步长和街机式油门/转向/刹车模型。车身俯仰与轮胎转动是视觉动画，而非四轮悬架的工程仿真。

## 响应式、性能与可访问性

流式 UI 与按视口纵横比计算的全岛镜头。窄屏提供专用驾驶控件；短横屏重排控件、隐藏辅助装饰。小地图实时跟随物理车辆，主内容可通过文字目录访问。

静态建筑按材质合并渲染；限制设备像素密度，自动画质在帧率较低时降低分辨率和阴影开销。设置中可显式选择高画质或节能模式。页面隐藏时停止模拟和绘制，窗口失焦清除输入；卸载时释放几何、材质、纹理、物理世界、声音节点与 WebGL 上下文。减少动态效果偏好关闭装饰动画，驾驶由用户主动启动。弹出面板具有焦点约束、关闭后的焦点恢复及 Escape 支持；WebGL 失败仍保留内容目录。

## 布娃娃、脚步与碰撞修正

- `residentPhysics.ts` 使用真实 Rapier 关节与多刚体模拟，独立同步头、躯干、手臂和腿部姿态。只启用站立复合体或布娃娃其中一种，避免重叠刚体把角色弹飞；CCD、额外求解迭代和腿部转角限制保持快速撞击稳定。
- 步态按实际移动速度播放，停住就停止摆腿。四足动物使用交错步序；按旋转后的脚部包围体抬起脚掌，去掉整体模型下沉的摆动。道路和草地拥有与表面高度匹配的碰撞；道路接缝使用斜边凸包，避免车辆和脚步被小台阶卡住。
- 车辆增加驾驶舱与行李体积，并将轮胎外缘纳入底盘碰撞；所有车辆碰撞体都可触发伤害。树冠用锥体、树干和路灯用柱体、石块用球体；围栏、花盆、路锥、营火石圈、摊位柜台、观景台与沙滩椅补上碰撞。
- 41 项自动化测试通过，新增实际 Rapier 测试验证行走不穿墙、冲击翻滚、关节连接与地面碰撞、安全起身。`ragdoll.js` 通过实际键盘碰撞检查七位岛民翻滚、身体碰撞体保持启用、关节间隙和恢复行走，并保留落地截图。
- “寻找岛民”先检查落点地面、完整车辆体积和前方通路，再选择朝向，避免车辆出现在营火或其他道具内部。生产预览还通过七位岛民掉血、零血量休息与恢复、树冠阻挡、边界碰撞和手机原生触摸圆盘检查。

## 自主游走与可见步态

- 七位角色独立选择家园附近 3–8 米的随机目的地，抵达后短暂停留，速度按物种区分。前方使用身体形状检测障碍，优先选择侧向绕行；持续受阻会重新选择目的地。倒地期间停止游走，起身后重新规划。
- 机器人加长腿部，行走时交替迈步、抬脚和反向摆臂；四足动物使用对角步序，小鸭和兔子交替抬脚，身体和头部随步态轻微摆动。动画相位按真实移动距离累计；速度跨多个物理帧采样，避免高刷新率下动作被错误减弱。停留时平滑停止摆动，减少动态效果偏好下不播放装饰性步态。
- `residentWander.test.ts` 验证自主漫游、停留、边界与受阻换向，物理测试验证前方障碍检测不会误判自己的身体或地面。`wandering.js` 在真实浏览器内连续采样七位角色的位置和腿部角度，验证移动范围与行走动画。
- Git 提交说明使用 `feat: 中文功能说明` 等中文约定格式。
- 本轮 44 项测试、代码检查与构建通过；生产预览验证七位角色自主移动和腿部动画，以及七位角色撞击后的布娃娃恢复和手机圆盘操作。

## 路障体积与可推动道具

- 路锥使用底座、锥身、白色环带三个匹配模型的碰撞体，共享一个动态刚体。底座边缘和尖顶都可碰撞，翻倒时整个模型与碰撞体同步，不留下固定的隐形路障。
- 车辆总质量归一化为 10；路锥 0.06、沙滩椅 0.35、木箱 0.4、花盆 0.8、长凳 1.1。可移动道具按质量接受碰撞推力，可翻倒、滑动并重新落地；动态物体启用 CCD 和额外求解迭代。花盆的花与长凳的腿随主体移动，长凳按座面和两条腿分别碰撞。
- `scenePhysics.ts` 统一创建场景刚体和复合碰撞体。47 项测试、代码检查与构建通过；新增测试覆盖路锥底座擦边、白环和尖顶体积、车辆撞开路锥、质量影响冲量响应。真实浏览器 `roadblocks.js` 验证道路路锥被车撞开，`wandering.js` 验证七位角色仍可自主游走和播放步态。

## 地形驾驶与岛屿时间

- 车辆使用真实轮胎尺寸的四个圆柱碰撞体、带离地间隙的凸包底盘、驾驶舱和行李体积。四点地面采样控制车身俯仰与侧倾，前进和倒车都能从静止状态通过低台阶、道路接缝与坡道；地形适配不直接改写车辆位置。
- 新增前进/倒车配对测试，验证低台阶、路面接缝、坡道与墙体阻挡，并采样真实接触流形的穿透深度。浏览器 `terrain.js` 通过真实键盘驾驶、停止后再次起步验证岛上坡道两种行驶方式的位移和高度。
